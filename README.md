# Trackada

## Ce que fait Trackada
Trackada est un outil en ligne de commande écrit en Node.js pur.

Il vérifie les fichiers dans required pour chaque projet dans track.json que le dossier du projet existe avec le bon nom et que Git est initialisé.

Il affiche si le dossier existe ou si il n'existe pas, le depot Git n'est pas initialisé, des fichiers manques et le pourcentage sur les projet initialisé correctement.

## Comment le lancer
1. Ouvrir un terminal.
2. Aller dans le dossier du projet (adapter le chemin à ton projet).
3. Lancer le script.
4. Répondre `o` à la question (Lancer la vérification ?(o/n)).
